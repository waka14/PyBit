# 11 前端交接包

Status: ready-for-human

## 目标

整理当前 PYBIT V2 本地实现，交给下一位前端开发者完成视觉、交互和手机响应式优化。

## 交付内容

- `FRONTEND_HANDOFF.md`：项目状态、业务边界、文件地图、验收要求。
- `FRONTEND_HANDOFF_PROMPT.md`：可直接发送给前端开发者或 AI coding agent 的执行 prompt。
- 当前 V2 源码、测试、迁移草案和已有开发文档。

## 当前限制

- 生产历史重算、Supabase migration、隔离库 RLS／事务实跑和正式发布未执行。
- 当前 `?demo=1` 仅在 Vite 开发模式启用，不能直接作为公开线上演示包。
- 最终视觉方向尚未批准，接手者不得改变账务口径和权限边界。

## 验收

- [x] 交接文档说明当前完成项与未完成项。
- [x] Prompt 包含阅读顺序、不可变规则、实施顺序和验收命令。
- [x] 交接包排除 `node_modules`、`dist`、`.env*`、`.git` 和其他 ZIP。
- [x] 本地测试、类型检查、构建和生产打包在本轮交接前已通过。
